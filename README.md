# 🏠 RentNest

RentNest is a rental property platform where tenants can find and rent properties, landlords can manage their listings, and admins can manage the platform.

## ✨ Features

* 🔐 Authentication & role-based access
* 🏠 Property listing, search & filtering
* ❤️ Watchlist
* 📩 Rental request management
* 💳 Stripe payment integration
* ⭐ Property reviews
* 👤 Tenant & Landlord dashboards
* 🛠️ Admin dashboard
* 📱 Responsive design

## 🛠️ Technologies

* Next.js
* TypeScript
* Tailwind CSS
* Express.js
* Prisma
* PostgreSQL
* Stripe

## 🚀 Run Locally

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
npm install
npm run dev
```

Create the required `.env` files and add your database, authentication, and Stripe configuration.

## 👥 User Roles

* **Tenant** — Browse properties, request rentals, pay, and submit reviews.
* **Landlord** — Add and manage properties and rental requests.
* **Admin** — Manage users, properties, rentals, and payments.
